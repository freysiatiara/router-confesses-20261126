An entry for make.fun's ["The Router Confesses"](https://make.fun/bounty/u-carbon-forge-the-router-confesses-f98f6b9e) bounty: a home Wi-Fi router excuses itself for dropping the connection at the climax of a movie. Title: "Stopped to Be Noticed".

## Run it

```sh
python3 main.py
```

This writes the entry line (97 characters) to `entry.txt` with no trailing newline. Set `ENTRY_OUTPUT` to choose a different output path.
